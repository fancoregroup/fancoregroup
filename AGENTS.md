- Preserve essa separação em commits e pull requests. Credenciais, dados CRM, currículos, transcrições, capturas internas e datasets reais, mesmo cifrados, ficam fora do Git público.
- Não execute coleta, migração do banco ou deploy como efeito de uma revisão de código.
- Use `node tools/campaign_reports/serve.cjs --demo` para desenvolver os painéis e mapas sem contas conectadas.
- Verifique mudanças de performance com os testes Python e Node descritos no README.
- Dados geográficos mantêm data, origem, licença e cobertura. Ausência de um valor não significa zero.
